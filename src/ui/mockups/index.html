Pick a look.

Six neo-brutalist / skeuomorphic directions for LLM Proxy. Open each to preview the landing page in that style, then tell me which one you want applied everywhere.

  • 01
    Classic Pop Brutalism
    Pastel cards, black borders, chunky offset shadows. The quintessential “Gumroad / neobrutalism-CSS” look.
  • 02
    CRT Terminal
    Dark background, amber phosphor, scanlines, monospaced everything. The sysadmin fantasy.
  • 03
    Swiss Editorial
    Thick rules, massive headlines, red/black/cream. Like a Helvetica manifesto that accidentally became a dashboard.
  • 04
    Memphis Arcade
    Primary colors, geometric confetti, playful offset shadows. 80s mall carpet energy.
  • 05
    Industrial Hardware
    Brushed metal, physical toggles, heavy bevels. Feels like rack-mount equipment.
  • 06
    Paper Punch
    Off-white paper, stark black, one electric-blue accent. Brutalism that still breathes.
